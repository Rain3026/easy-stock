## 一、讨论收敛后的最终范围

| 已确认内容 | 实现约束 |
| --- | --- |
| 原今日总览保持 | 原页面、默认入口、设置与数据保留；如抽取共享渲染逻辑，必须验证其原行为与布局不变。 |
| 增加观澜 | 一个日常使用页，只读取一个启用配置；显示配置名称/版本、当前行情和有明确截止时间的研究结果。 |
| 管理与使用分开 | 底部独立菜单“看板与组件”，放在“系统设置”上方，二者同级。 |
| 两个管理TAB | “我的看板”管理观澜配置版本；“组件库”管理组件及预设。编辑/参数/预设是内部页面或侧栏。 |
| 单页、多版本 | 不设置盘中看盘/盘后研究两个独立应用看板，不增加多看板切换下拉。 |
| 配置历史列表 | 每页默认2条，竖向排列；每条左侧名称、版本、时间和操作，右侧大缩略图；搜索、滚动、分页。 |
| 选择与启用分开 | 选中用于复制等操作；预览不启用；启用指针独立、唯一。 |
| 新建与复制 | 空白新建或从所选历史版本复制，选择是否复制业务参数及尺寸样式，创建后编辑草稿。 |
| 可组合编辑器 | 左画布、右侧默认组件库；拖入或点击添加，允许同类组件多实例；可移动和八方向缩放。 |
| 内容也能调 | 各实例可调标题、数字与说明字号、标题栏/图表高度、留白、间距、密度和适用内部排列。 |
| 数据参数独立 | 指数选择、关注名单、研究结果绑定等按组件能力开放；每个实例独立保存。 |
| 组件库可管理 | 数量/分类/搜索/预览/收藏/隐藏/默认参数/预设/引用版本查询；与编辑器共用注册清单。 |
| 安全保存 | 应用到草稿、保存新版本、保存并启用分开；取消不改变已启用配置；不整页刷新。 |
| 配置不等于分析 | 拖动/缩放/保存/复制/启用不触发AI。显式行情刷新与重新研究分开。 |

“我的看板”保留用户熟悉的菜单名称，内部数据对象称为“配置版本”，避免误解为多个独立业务看板。更多菜单中的删除采用可恢复归档；正在启用的版本需先切换到其他版本，才能归档。历史配置内容不可改写，重命名只改独立的显示元数据。

首次没有保存版本时显示新建引导，不写入设计稿中的V4/V5、示例日期或模拟金融结论。示例图片中的所有数字均只用于布局参考。

## 三、页面和入口关系

| 入口 | 内容与去向 |
| --- | --- |
| 今日总览 | 原页面与原默认入口。 |
| 观澜 | 启用配置的实时视图；刷新行情、打开对应五工作区/报告详情。无编辑齿轮或缩放手柄。 |
| 看板与组件 → 我的看板 | 版本列表、搜索分页、选中、预览、启用、归档恢复；新建/复制后进入草稿编辑。 |
| 草稿编辑内部页 | 画布 + 右侧组件库/组件设置；设置含数据/尺寸/样式；保存新版本或保存并启用。 |
| 看板与组件 → 组件库 | 查看、收藏/隐藏、默认参数、我的预设与引用版本；添加组件进入草稿，不直接改变观澜。 |
| 系统设置 | 保留原模型/凭据/Skill/MCP等全局配置，管理页不复制一套。 |

新路由采用现有hash机制，并保持旧地址兼容。新入口不强行改为第六个业务工作区；路由命名和类型在GL-002冻结后执行。页面切换只改变视图，数据订阅与配置状态有独立生命周期。

## 四、八类首批组件及数据获取方式

| 类别 | 组件 | 复用对象与可配置内容 | 可用性验收边界 |
| --- | --- | --- | --- |
| 行情 | 沪深量能 | 现有marketpulse/overview；实际与预计额、量柱、前20日均额、实例显示参考线、图表空间。 | 实际/预测不混同；原规则观察线不变；ES5真实分时验收单独保留。 |
| 行情 | 指数参照 | 已支持指数报价/历史；单指数或多指数、显示方式、字段与顺序。 | 逐指数记录口径、源时间及缺口；纳指100不能用纳指综合代替。 |
| 行情 | 市场宽度 | 已有同口径主备宽度；涨跌平、占比、显示字段。 | 集合/时点及部分数据状态明示，不填假零。 |
| 行情 | 涨跌停与连板 | 现有短线情绪、涨跌停及梯队；摘要、数量、高度/梯队显示。 | 原口径复用，缺字段可辨。 |
| 行情 | 核心主线 | 现有题材/主线服务；摘要条数、排序和字段。 | 事实热度和AI观点不混写；详情回到机会发现。 |
| AI研究 | 多空辨析 | 已保存研究结果/共同证据/任务状态；研究对象、结果绑定及摘要层级。 | 没有报告就显示尚无结果；保留证据截止、方法和模型引用，不自动分析。 |
| AI研究 | 持仓风险 | 既有组合巡检结果；组合对象、结果引用和风险摘要。 | 不修改持仓或重跑模型；私人结果仅本地展示，缩略图脱敏。 |
| 关注 | 自选观察 | 先审计现有关注名单，缺失才补最小共享名单；股票名单、列/排序。 | 可手动调整输入，列表事实和实例显示设置分开；不复制成第二份持仓。 |

这8类是首版计划范围，当前并没有已上线的观澜组件注册库。现有服务可复用也不等于所有字段当前新鲜可得；GL-002逐项完成接口和字段核对。

组件不要求与一个MCP或一个Skill一一对应。组件接收统一的结构化结果，可来自数据库/行情缓存、确定性规则，或已有Agent+Skill结果。MCP作为现有受控取证工具留在数据与Agent链路内，不能让展示层绕过原权限和任务控制。当前市场判断属于确定性规则，不标成Agent分析。

新增类型采用注册描述、配置schema、结果适配器和渲染器扩展；本期不做任意脚本上传、任意MCP命令绑定或第三方组件市场。

## 五、配置与数据的所有权

| 对象 | 保存什么 | 变更规则 |
| --- | --- | --- |
| 配置草稿 | 来源版本、实例集合、布局、参数、样式、修订号。 | 可编辑；持久化恢复；未保存不影响观澜。 |
| 配置版本 | 完整配置快照、schema版本、序号、创建时间、来源及脱敏缩略图引用。 | 保存后不可变；修正需生成新版本。显示别名/归档状态为独立元数据。 |
| 启用指针 | 唯一版本ID及并发修订号。 | 只有明确启用或保存并启用才改变，事务保证原子性。 |
| 组件实例 | 唯一ID、类型/schema、受支持结果绑定/参数、位置宽高和样式。 | 当前草稿内独立配置；复制版本生成新实例ID。 |
| 组件注册/默认 | 类型、能力、配置项、最小尺寸、系统/用户默认。 | 只影响后续新增；隐藏不破坏旧实例。 |
| 组件预设 | 可复用参数/尺寸/样式。 | 添加时复制；编辑/删除预设不追改实例。 |
| 行情/研究/持仓/名单 | 原服务中的业务事实与结果。 | 不嵌进布局版本当事实副本，不因删除配置/组件而删除。 |

存储方向：按现有DataDir规则增加专用本地SQLite配置Store，避免修改已有业务表和研究记录语义；使用schema版本、幂等初始化、事务、输入校验及乐观并发。具体文件/包路径在GL-002固定，GL-004用隔离数据库验证。浏览器与桌面共享合同，测试不得直接针对原业务数据库。

版本缩略图是布局记录，不能作为实时行情。默认使用示意或脱敏数据；含私人数据的验收材料只留在受保护本地位置，不进入`frontend/public`、Git或公开交付证据。即使启用很早的布局，行情仍按当前有效来源读取，AI报告仍按原证据时点显示。

## 六、效率与Agent边界

1. 复用现有服务与缓存，按能力/业务参数合并读请求；多个同口径组件不分别扫描全市场。
2. 拖动、缩放及样式编辑主要是本地草稿变更。保存配置不使整页刷新，也不强制重采已有行情。
3. 新增/启用配置显示不同对象时，允许必要的共享数据读请求；缓存缺失由原服务按既定策略有界补取。这不等于每次布局操作都发起行情重采。
4. 可见页订阅行情更新，离开页面取消无用订阅；各卡片分别更新。单源慢或研究缺失不阻塞其他组件。
5. Agent结果只读已有档案/任务状态；打开页面、添加、复制、保存、启用、行情刷新都不启动新模型任务。
6. 需要新研究时跳转现有研究入口，沿用快照/设置/方法指纹去重、恢复及费用控制；本计划默认不进行真实模型调用。
7. 事实交易时间、拉取时间、缓存状态、规则计算时间、AI证据截止及生成时间分别表达。新数据不回写旧判断。
8. 已有Skill反馈/候选/评估/发布机制继续复用，本任务不扩张为Skill自动进化重构，更不因组件库新增而自动发布候选。

## 八、验收与现有任务衔接

核心验收链：从我的看板新建/复制 → 编辑器拖入多个同类组件 → 移动/八方向缩放 → 修改标题/数字字号和业务参数 → 保存新版本 → 预览不启用 → 明确启用 → 观澜原地呈现 → 重启后保留。另验证取消、保存失败、双窗口冲突、旧schema、离线和缺数据。

原今日总览、五工作区路由、历史研究、持仓与全局设置须有回归/保护核对。相关单元与集成测试随实现补齐，最后进行串联验收；不为每个低风险样式项编写仅复述实现的测试。UI须查看真实渲染和操作，构建成功不等于视觉通过。Web和macOS桌面分别验证；未实测平台明确保留限制。

当前五工作区正式记录为`docs/plans/five-workspaces/STATE.md`。本轮只读取其中状态，未重新取行情或执行实盘验收。该记录仍有ES5-004/ES5-041的真实数据验收缺口及其他限制；已有`easystock-es5`采样计划独立保留。本计划不修改旧任务账本、证据、采样时间或自动调度。

配置/编辑功能可独立开发，不必等待三天行情样本；受影响组件如继承真实数据缺口，验收逐项明示。不能把隔离fixture、盘后回放、设计稿数字或样本数量当作真实数据质量/预测有效性证明。
