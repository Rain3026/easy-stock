# 观澜、我的看板与组件库

本地入口：<http://127.0.0.1:20073/#boards/versions>。刷新原页面即可看到新增导航，今日总览和默认首页保持。

## 第一次使用

1. 打开左下“看板与组件”→“我的看板”，点“新建配置”。
2. 输入名称，选择空白或复制已有版本，点“创建并编辑”。
3. 从右侧拖入组件，或点“＋”。同类组件可以加多份，例如创业板与沪深300分别配置。
4. 拖动卡片标题左侧手柄移动；边和角支持八个方向缩放。方向键也可移动，Shift加速。拖入时Esc取消。
5. 点齿轮，在“数据 / 尺寸 / 样式”中调整参数、像素宽高、位置、字号、标题栏高度、留白和内部排列。关闭网格吸附可逐像素调整。
6. “应用到草稿”保存编辑进度；“保存版本”新增历史记录；“保存并启用”同时让观澜使用新版本。

首次没有配置时，观澜显示引导。验收用配置没有复制到日常数据中。

## 配置版本

“我的看板”是一个观澜页面的配置历史，每页两条。左侧显示名称、版本、配置时间、组件数和操作，右侧缩略图只示意布局，不包含行情或私人研究。

选中用于复制，预览不启用。启用旧版恢复布局和参数，行情继续读取当前有效数据，AI研究保留原证据时点。已保存配置主体不可修改；重命名仅修改显示名称。更多菜单可归档和恢复，当前启用版不能直接归档。

取消编辑可保留草稿、继续编辑或放弃草稿，已保存和启用版本不受影响。离线改动保留在本机；并发冲突会阻止覆盖，可复制本机改动为新草稿。浏览器清理站点存储会移除尚未写入服务器的本机恢复内容，已写入数据库的草稿仍保留。

## 组件库、默认和预设

初始八类：沪深量能、指数参照、市场宽度、涨跌停与连板、核心主线、多空辨析、持仓风险、自选观察。

- 组件库和编辑器使用同一目录，支持搜索、分类、收藏、隐藏、真实预览及配置版本引用查询。
- 默认参数只影响之后新增的实例。现有实例、草稿和历史版本不追改。
- 预设保存参数、尺寸和样式，不保存行情、报告正文或凭据。可从实例另存，也可在库中新建、复制、修改、重命名、删除或添加到草稿。
- 指数支持单个或多个、排列顺序和显示字段；自选观察使用独立共享名单，不改写持仓方案。
- 隐藏组件类型只从添加列表隐藏，已有实例继续显示。移除实例不删除关注名单或原研究。

## 数据与维护

行情组件共用现有行情读取和缓存；多空辨析、持仓风险只读取已保存结果，可绑定研究对象、快照、组合或具体记录。失败、缺失、过期和部分数据明确标识，布局操作不会启动模型。

“刷新行情”与重新开展AI研究分开。需要新分析时进入原研究中心或持仓管理；Skill/MCP安装、运行时和凭据仍在原系统设置。

新增配置存于设置文件同目录的`guanlan.db`，包含草稿、不可变版本、启用指针、默认、预设和共享名单；现有业务数据库独立。schema与接口见[CONTRACT.md](CONTRACT.md)。

需要恢复时先停止对应本地服务，从`.runtime/guanlan/backup-path`指向的受保护备份选择具体对象恢复；不要用旧备份覆盖后来新增的数据。旧设置、业务数据库和已有改动的核对记录见`evidence/protection-before-local-update.json`与最终保护记录。

此次验证覆盖Web和macOS Electron本地运行，未替换全局安装，未发布安装包。Windows/Linux尚未实际运行验证。ES5盘中量能与备用源的实盘验收沿用原任务记录，此次布局开发不解除其缺口。
